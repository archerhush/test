Test procedure

  1. Open this file in Firefox with Tridactyl enabled. If visual mode does not activate on a local file, serve the file over localhost instead.
  2. Find MIDDLE START using your usual search workflow, or select a few words there with the mouse. Enter Tridactyl visual mode.
  3. Press 3j repeatedly until you pass MIDDLE END. Note which pane the moving end of the selection enters.
  4. Press k repeatedly. Check whether it retraces the selection or gets stuck. Watch the anchor/focus readout below.
  5. Exit visual mode before changing controls. Compare the three DOM orders, independent versus whole-page scrolling, and a short middle pane.

The default DOM order is deliberately different from the visible order. There are no keydown handlers, focus traps, or selection-modifying scripts on this page. The readout only observes selection changes. Text after the panes is also selectable, so movement can eventually reach these instructions.
